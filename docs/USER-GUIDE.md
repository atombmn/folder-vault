# Folder Vault: a guide for staff

Folder Vault lets you put a password on a folder on your computer.

When the folder is **locked**, nobody can see what is inside it, not even
someone who signs in to Windows with your account. When you **unlock** it with
its password, your files are there as normal.

The folder password is not your Windows password. Choose a new one.

---

## Protect a folder

1. Open **File Explorer** and find the folder.
2. **Right-click** the folder.
   On Windows 11, click **Show more options** at the bottom of the menu first.
3. Click **Protect with Folder Vault...**
4. Type a password, then type it again.
   A short sentence is easy to remember and hard to guess, for example
   *Mangoes ripen in March 2027*. It must be at least 12 characters.
5. Tick the box and click **Protect folder**.
6. Wait for the message that says it is done. A big folder can take a few minutes.

The folder is now locked. It stays in the same place, with the same name.

## Which folders can I protect?

Any folder of your own on this computer, for example:

- a folder in **Documents**, **Desktop** or **Downloads**, such as `Documents\Payroll`;
- a folder in **OneDrive**, such as `OneDrive\Documents\HR`;
- a folder on another drive of this computer, such as `D:\Accounts`.

You cannot protect a whole Documents, Desktop or OneDrive folder (make a
folder inside it and protect that), other people's folders, Windows or program
folders, or folders on USB sticks and network drives. If a folder cannot be
protected, the window tells you why.

**Two things to know first:**

- **A folder in OneDrive stops syncing once it is protected.** It disappears
  from OneDrive online and from your phone or other computers, and the files
  are kept only on this computer. Folder Vault asks you to confirm this first.
  If some of its files are "online-only", right-click the folder, choose
  **Always keep on this device**, wait for the green ticks, then protect it.
- **A folder outside your own user folder** (such as `D:\Accounts`) can then
  be opened only by you. If colleagues use that folder too, ask IT to make it
  a shared folder instead (see *Share a folder with colleagues*).

## Open a locked folder

Any of these works:

- **Open the folder** as usual. Inside you will see one item:
  **Locked - double-click here to unlock**. Double-click it and type the password.
- **Right-click** the folder and choose **Unlock with Folder Vault...**
- Click the **shield icon** near the clock (bottom right of the screen) and choose
  **Unlock** with the folder's name.

The folder opens with all your files.

## Lock it again

You usually don't need to do anything. The folder locks by itself when:

- you lock the screen (press the **Windows key + L**)
- you sign out or shut down
- the computer has been left alone long enough for the screen to lock

To lock straight away, without locking the screen:

- press **Ctrl + Alt + L**, or
- click the **shield icon** and choose **Lock all my folders now**, or
- right-click the folder and choose **Lock with Folder Vault**.

**Save your work before you lock the screen.** If a document from the folder is
still open, Folder Vault locks the folder anyway when you walk away, and anything
you had not saved in that document is lost.

## Share a folder with colleagues

Your IT person can set up a shared area on a computer, for example `C:\Shared`.
A folder protected inside that area can be opened by anyone who uses that
computer **and** knows the folder's password.

Tell people the password face to face. Don't send it by WhatsApp, SMS or email.

When someone leaves, change the password (see below) and tell the others.

## Change a folder's password

1. Click **Start**, type **Folder Vault** and open it.
2. Click the folder in the list.
3. Click **Change password...**, type the old password and the new one twice.

## Stop protecting a folder

1. Open **Folder Vault** from the Start menu.
2. Click the folder, then **Remove protection...**
3. Type the password.

Your files go back into the folder as a normal, unprotected folder.

## If something goes wrong

| What you see | What to do |
|---|---|
| "That password is not correct" | Check Caps Lock and try again. After a few wrong tries you have to wait a little before the next one. |
| "Too many wrong passwords" | Wait 15 minutes, or call IT. |
| "A file is still open in another program" | Save and close that file (Word, Excel, PDF), then try again. |
| "The background service is not running" | Restart the computer. If it happens again, call IT. |
| "Could not confirm it is talking to the genuine background service" | **Do not type your password again.** Call IT straight away. |
| You forgot the password | Call IT. They can recover the folder. Nobody else can. |
| "That folder cannot be protected" | The message says why. Usually: choose a folder inside it, not the whole Documents or OneDrive folder. |
| "Some files in that folder are only in OneDrive online" | Right-click the folder, choose **Always keep on this device**, wait for the green ticks, try again. |

## Please

- Don't write the folder password on paper or in a file on the computer.
- Don't use your Windows password, your phone PIN or your name.
- Don't let anyone watch you type it.
- Lock the screen (**Windows key + L**) every time you leave your desk.
